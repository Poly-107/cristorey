PASO 1 - ROL IAM PARA EC2
=====================================================================
[ ] IAM > Roles > Create role > AWS service > EC2 > Next.
[ ] Create policy > JSON > pegar:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket"],
      "Resource": "arn:aws:s3:::cristorey-uploads-TU_SUFIJO"
    },
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject"],
      "Resource": "arn:aws:s3:::cristorey-uploads-TU_SUFIJO/*"
    },
    {
      "Effect": "Allow",
      "Action": ["ses:SendEmail", "ses:SendRawEmail"],
      "Resource": "*"
    }
  ]
}

[ ] Nombre de la policy: CristoReyEC2Policy
[ ] Nombre del rol: CristoReyEC2Role
[ ] Adjuntar la policy al rol.
[ ] No guardar access keys en .env: la EC2 usara este rol.

PASO 3 - BUCKET S3
=====================================================================
[ ] S3 > Create bucket
      Nombre: cristorey-uploads-TU_SUFIJO  (unico global)
      Region: sa-east-1

[ ] Block Public Access:
      - Mantener activado el bloqueo de ACLs.
      - Desmarcar "Block public and cross-account access to buckets
        and objects through any public bucket or access point policies".

[ ] Permissions > Bucket policy > pegar (cambiar nombre de bucket):

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadCatalogImages",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::cristorey-uploads-TU_SUFIJO/*"
    }
  ]
}

[ ] Properties > Bucket versioning > Enable.
[ ] Anotar la URL: https://cristorey-uploads-TU_SUFIJO.s3.sa-east-1.amazonaws.com

=====================================================================

  php8.3-mbstring php8.3-curl php8.3-zip php8.3-bcmath php8.3-intl \

sudo php /tmp/composer-setup.php --install-dir=/usr/local/bin --filename=composer

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -

  https://truststore.pki.rds.amazonaws.com/global/global-bundle.pem

PASO 10 - NGINX
=====================================================================
[ ] sudo nano /etc/nginx/sites-available/cristorey

server {
    listen 80;
    server_name TU_IP_ELASTICA;
    root /var/www/cristorey/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

[ ] Activar y recargar:

sudo ln -s /etc/nginx/sites-available/cristorey /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
